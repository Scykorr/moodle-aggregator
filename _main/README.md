# Развитие проекта Moodle

Новая работа ведётся в `federation/`: объединение независимых Moodle через
единый источник учётных записей. Исходный Docker-стек находится в корне
репозитория; перемещение работающего стека может изменить имена Compose volumes.

В Git хранятся только инструкции, конфигурационные шаблоны и исходники утилит.
Секреты `.env`, данные студентов, резервные копии, Docker-образы, EXE и сборки
остаются локально. Перед коммитом: `python scripts/check_repository.py`.
